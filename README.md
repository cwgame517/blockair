# 블록에어 크래프트 (로블록스)

하늘 섬에서 내 비행기로 블록을 캐고, 캔 블록으로 비행기를 고치고, 함께 싸우는 로블록스 게임입니다.

- 기획서: https://claude.ai/artifact/Lf8rEK89RVs7yV9DAL6sTP
- 성장 수치표: https://claude.ai/artifact/HRC8X2kCqXdgjqVE1J4b9H
- 개발 구조 설계서: https://claude.ai/artifact/VtwfGBKW9MZRMymb3kbj9E

## 처음 설정 (한 번만)

1. 설치: [Roblox Studio](https://create.roblox.com/), [VS Code](https://code.visualstudio.com/), [Git](https://git-scm.com/), [Rokit](https://github.com/rojo-rbx/rokit)
2. 이 저장소를 받은 폴더에서 `rokit install` → Rojo 7.4.4가 설치됩니다.
3. Studio에 Rojo 플러그인 설치: 터미널에서 `rojo plugin install`
4. Roblox에서 경험(게임)을 하나 만들고, 그 안에 플레이스를 하나 더 추가합니다 (허브 + 원정 섬).
5. Studio에서 게임 설정 → 보안 → **API 서비스에 대한 Studio 접근 사용** 켜기 (저장 테스트에 필요).

## 매일 하는 작업

```bash
rojo serve                      # 허브 플레이스 작업할 때
rojo serve island.project.json  # 원정 섬 플레이스 작업할 때
```

Studio에서 해당 플레이스를 열고 Rojo 플러그인의 **Connect**를 누르면 `src/`의 코드가 들어갑니다. 그다음 플레이(F5)로 테스트합니다.

## 폴더

| 경로 | Studio 위치 | 내용 |
|---|---|---|
| `src/shared/` | ReplicatedStorage.Shared | 양쪽 공통: Config(수치), Net(신호 이름), 도구 |
| `src/server/common/` | ServerScriptService.Server.common | 두 플레이스 공통 서버 서비스 |
| `src/server/hub/`, `src/server/island/` | ServerScriptService.Server.place | 플레이스 전용 서비스 |
| `src/client/` | StarterPlayerScripts.Client | 컨트롤러와 UI 화면 |
| `data/blocks_v2.csv` | (없음) | 블록 36종 원본 |
| `tools/export_config.py` | (없음) | CSV → `Config/Blocks.luau` 생성 |
| `places/` | (없음) | Studio 플레이스 파일 |

수치를 바꿀 때는 코드 대신 `src/shared/Config/`를 고칩니다. 블록 CSV를 고쳤으면 `python tools/export_config.py`를 실행합니다.

## 규칙

- 서버가 정답을 가집니다. 코인·블록·HP는 서버만 바꾸고, 클라이언트는 요청만 보냅니다.
- 서비스(서버)와 컨트롤러(클라이언트)는 `Init(목록)`과 `Start()`만 갖습니다. `Main`이 모두 Init한 뒤 모두 Start합니다.
- 숫자는 코드에 쓰지 않고 `Config`에서 읽습니다.

## 비행 (1단계)

- 허브에 들어가면 아래 가운데 **비행기 타기** 버튼(PC는 **F** 키도 됨)을 누르면 머리 위에 기본 비행기가 나타나고 바로 탑니다.
- PC: 마우스 또는 W/A/S/D(방향키)로 방향, Shift 빨라지기 / Ctrl 느려지기, F로 내리기
- **M 키**: 마우스 조준 ↔ 화면 스틱 바꾸기. Studio에서는 화면 스틱(마우스가 잠기지 않음)으로 시작하고, 실제 게임 PC에서는 마우스 조준으로 시작합니다.
- 모바일: 왼쪽 스틱으로 방향, 오른쪽 막대로 속도(늘 앞으로 감), 위쪽 **내리기** 버튼
- Studio에 `HubMap`이라는 맵이 없으면 코드가 임시 공항 섬을 만듭니다. 나중에 Studio에서 맵을 만들어 이름을 `HubMap`으로 두면 임시 맵은 생기지 않습니다.
- 비행 손맛(속도·회전·카메라 거리)은 `src/shared/Config/Flight.luau`에서 바꿉니다.
- 비행기 모양(칸 배치)은 `src/shared/Config/FrameShapes.luau`에 있습니다.

## Studio 테스트 명령 (Studio에서만 동작)

채팅창에 입력합니다.

- `/coins 1000` 코인 더하기 (음수면 빼기)
- `/xp 500` XP 더하기
- `/stats` 출력 창에 내 레벨·코인 표시
- `/speed 70` 비행 속도를 기본의 70%로 (10~300). 날고 있는 비행기에도 바로 적용. 다시 시작하면 100%로 돌아감
- `/give 100` 창고에 블록 100개 넣기 (팔기 테스트)
- `/hurt 300` 내 비행기 HP 300 깎기 (수리 테스트). HP 가 0 이 되면 격추되어 가장 가까운 격납고로 돌아감
- `/allblocks 20` (허브) 블록 36종을 종류마다 20개씩 창고에 넣기 (에디터 테스트)
- `/level 5` 레벨을 바로 5로 (부위 교체 테스트)

## 하늘 섬 (2단계)

- 허브에서 **출격**을 누르면 원정 섬 플레이스의 나만의 서버로 이동합니다. (Studio 테스트에서는 이동이 안 되고 알림만 뜸)
- 섬에 도착하면 바로 비행기에 탑니다. 화면 아래 **허브로** 버튼(비행기에서 내렸을 때 보임)으로 돌아갑니다.
- **제자리 비행(캐기)**: 속도를 맨 아래(0)까지 내리면 드론처럼 멈춰 떠 있습니다. 좌우로 돌고 W/S(스틱 위아래)로 천천히 앞뒤로 움직이며, 카메라가 아래를 내려다봅니다. 폭탄은 바로 아래로 떨어집니다. 속도를 올리면 다시 날아갑니다.
- **채굴 폭탄**: PC는 Space, 모바일은 오른쪽 아래 **폭탄** 버튼. 땅에 보이는 흰 원이 떨어질 곳입니다. 플레이어는 다치지 않습니다.
- 단단한 블록은 여러 번 맞아야 깨지고, 맞을수록 어두워집니다(균열 3단계). 깨는 횟수 = 올림(블록에 필요한 채굴력 ÷ 내 채굴력).
- 깨진 블록은 **캔 사람 화면에만** 보이며 0.5초 뒤 비행기로 날아와 화물칸에 들어갑니다. 금광석·보석은 바로 코인. 석탄·석유·우라늄(연료)은 다음 단계에서 효과가 생깁니다.
- 화물칸이 가득 차면 블록이 빨갛게 사라지고 경고가 뜹니다. 비행기 아래 상자가 차오를수록 커지고 가득 차면 금빛이 됩니다.
- 화물은 격납고에 맡겨야 창고로 들어갑니다 (3단계 참고). 맡기지 않고 허브로 가거나 게임을 나가면 사라집니다.
- 섬은 서버가 시작할 때 씨앗 번호로 만듭니다. 클라이언트도 같은 씨앗으로 똑같이 만들어 겉면만 그리므로 내려받을 것이 거의 없습니다. 출력 창에 걸린 시간이 찍힙니다.
- 섬 모양·층·광맥 수는 `src/shared/Config/Islands.luau`, 폭탄 궤도는 `Config/Mining.luau`, 블록 색은 `Config/BlockLooks.luau`에서 바꿉니다.

### 원정 섬 플레이스 만들기 (한 번만)

1. 허브 플레이스를 Studio에서 열고 **파일 → Roblox에 게시**로 게시합니다. (이미 했으면 건너뜀)
2. 위쪽 메뉴 **창(Window) → 자산 관리자(Asset Manager)**를 엽니다.
3. **Places(플레이스)** 폴더를 두 번 눌러 들어가서 빈 곳을 오른쪽 클릭 → **Add New Place(새 플레이스 추가)**.
4. 새로 생긴 플레이스를 두 번 눌러 엽니다. 이 창에서 `rojo serve island.project.json` 을 실행하고 Rojo 플러그인 **Connect** → 플레이(F5)하면 섬이 나옵니다.
5. 이 상태에서 **파일 → Roblox에 게시**를 한 번 해 둡니다. 출격(텔레포트)은 두 플레이스가 모두 게시된 뒤 Roblox 앱에서만 시험할 수 있습니다.

플레이스 번호는 코드가 자동으로 찾습니다(플레이스가 2개일 때). 3개 이상이 되면 `Config/Places.luau`에 번호를 적습니다.

### 섬 테스트 명령 (Studio, 채팅창)

- `/power 5` 내 채굴력을 5로 (숫자 없이 쓰면 원래대로). 기본 나무 비행기는 1

## 격납고와 코인 (3단계)

### 원정 섬 격납고 4곳

- 섬 가장자리 바깥 동서남북에 하나씩 있고, 멀리서도 **격납고** 글자가 보입니다. 섬에 도착하면 이 중 한 곳에서 시작합니다(재출격 지점).
- 위의 **빛나는 파란 원기둥** 안으로 날아 들어가면 화물이 바로 창고에 맡겨집니다 ("+32 블록 보관됨").
- 원기둥 안에 **3초** 머물면 HP 가 가득 찹니다(무료). 속도를 맨 아래로 내려 제자리 비행하면 쉽습니다. 맞은 지 5초 안에는 수리가 시작되지 않습니다.
- 맡길 때 블록 1개당 XP 1 (`Config/Levels.luau` 의 `XP_PER_DEPOSIT`). 레벨 2까지 100 XP.
- 맡기지 않은 화물이 있을 때 **허브로**를 누르면 한 번 경고하고, 한 번 더 누르면 출발합니다(화물은 사라짐).
- 날 때 화물칸 아래에 **HP 막대**가 보입니다. 무기·몹은 6단계라 지금은 `/hurt` 로만 깎입니다.
- 격납고 위치·크기·수리 시간은 `src/shared/Config/Hangars.luau` 에서 바꿉니다.

### 원정 결과 화면

- 섬에서 허브로 돌아오면 **원정 결과**(캔 블록·맡긴 블록·사라진 블록·보물 코인·XP·레벨 업)가 한 번 뜹니다.
- Studio 섬에서는 이동이 안 되므로 **허브로**를 누르면 결과 화면을 미리 보여 줍니다.

### 허브 격납고 창

- 허브 아래 가운데 **격납고** 버튼을 누르면 창이 열립니다.
- **창고 (팔기)**: 맡긴 블록이 종류별로 보입니다. 줄마다 **팔기**, 위쪽 **전부 팔기**. 값은 블록 표의 판매가(`data/blocks_v2.csv`)입니다.
- **강화**: 화물칸·폭탄 범위·폭탄 재장전·폭탄 위력을 코인으로 한 단계씩 올립니다. 레벨이 열어 준 단계까지만 됩니다(레벨 3/8/15/25). 무기 강화는 6단계에서 엽니다.
- 강화 값과 비용은 `src/shared/Config/Upgrades.luau` 에 있습니다. 올린 강화는 다음 출격부터 섬에서 적용됩니다.

### 출격 이동 시험 (게시 후 Roblox 앱에서)

Studio 안에서는 플레이스 이동이 안 되므로, 두 플레이스를 게시한 뒤 실제 게임에서 확인합니다.

1. 허브: Studio에서 허브 플레이스를 열고 `.\rojo.exe serve` → Rojo **Connect** → 위쪽 메뉴 **파일 → Roblox에 게시** (Alt+P).
2. 터미널에서 Ctrl+C 로 serve 를 멈춥니다.
3. 원정섬: Studio **창 → 자산 관리자 → Places** 에서 **원정섬**을 두 번 눌러 엽니다. `.\rojo.exe serve island.project.json` → Rojo **Connect** → **파일 → Roblox에 게시**.
4. 웹의 [크리에이터 허브](https://create.roblox.com/dashboard/creations) → 내 게임 카드를 눌러 들어가서 **Roblox에서 보기**(View on Roblox) → 초록색 **플레이** 버튼.
5. 허브에서 **출격** → 원정섬 도착 → 블록 캐기 → 격납고에 맡기기 → **허브로** → **격납고** 창의 창고에 블록이 와 있으면 성공.

## 비행기 에디터 (4단계)

### 조립 자리 (채우기·칠하기)

- 허브 아래 **내 비행기** 버튼을 누르면 내 조립 자리 앞으로 갑니다. 공항 섬 동쪽에 노란 테두리 자리 12개가 있고, 들어온 순서대로 한 자리씩 받습니다. 자리 위에 내 비행기가 크게 놓여 있고 이름표가 뜹니다(다른 사람도 보여요).
- 자리 근처에 서 있으면 에디터 화면이 뜹니다. 걸어 다니며 비행기 칸을 **클릭(모바일은 탭)** 하면 바뀝니다.
- 아래 단축바: 창고 블록 목록과 **빼기**. 블록을 고르고 칸을 누르면 채워지고, 반대쪽 칸도 같이 바뀝니다(블록 2개 듦. 가운데 줄 칸은 1개).
- 도구: **한 칸** / **부위 채우기**(누른 칸의 부위 전체) / **칸 색칠**(누른 칸만, 반대쪽 칸도 같이. **원래 색**으로 되돌림) / **부위 색칠**(누른 칸의 부위 전체, 그 부위의 칸 색은 지워짐) / **자동 채우기**(가진 좋은 블록을 가운데 칸부터) / **모두 빼기**.
- **모양**: 원작과 같은 모양 블록 8종(사각형·사각형¾·반사각형·반반사각형·삼각형·반삼각형·계단·막대기). 모양을 고르고 칸을 누르면 바뀌고(반대쪽 칸도 대칭으로), 같은 모양으로 다시 누르면 방향이 돌아갑니다(8방향: 4방향 × 뒤집기, 막대기는 눕힘·세움). 모양은 꾸미기라 블록 수·성능은 그대로. 틀의 처음 모양(기수 끝 경사 등)은 `Config/FrameShapes.luau`, 모양 목록은 `Config/BlockShapes.luau`.
- 넣은 블록은 창고에서 빠지고(팔 수 없음), 빼면 창고로 돌아옵니다. 반투명 칸은 기본 블록(나무, 공짜)입니다.
- 오른쪽: **속도·튼튼함·화력·채굴력** 막대. 블록을 바꾸는 순간 숫자와 +/- 가 보입니다. 가벼운 블록 = 빠름, 단단한 블록 = HP, 좋은 블록 = 채굴력. 너무 무거우면 "부스터 힘이 부족해요"가 뜨지만 출격은 됩니다.
- 무기: 기관포·미사일·레이저 중 하나 (6단계에서 실제로 쏩니다. 지금은 화력 막대와 총 색만 바뀜).
- **설계 1·2·3**: 비행기 3대를 저장. 바꾸면 지금 비행기 블록은 창고로 돌아가고, 고른 설계대로 창고에서 다시 채웁니다(모자란 칸은 기본 블록).
- **시험 비행**: 바로 타서 바뀐 속도를 느껴 봅니다. 섬에 출격해도 이 비행기로 날고, 채굴력도 적용됩니다.

### 부위 교체 (레벨 5)

- 자리 앞쪽 오른편 **키오스크**에 다가가 **E**(모바일은 버튼) 또는 오른쪽 **부위 교체** 버튼.
- 아래 탭 **기수·날개·꼬리**를 누르면 카메라가 그 부위로 날아갑니다. ◀ ▶ 로 모양(각 3종)을 넘기면 미리보기와 막대 변화가 보이고 **적용**을 눌러야 바뀝니다.
- 바뀐 부위의 블록은 창고로 돌아갔다가 새 모양에 자동으로 다시 채워집니다(좋은 블록이 가운데 칸부터). 색은 부위에 저장돼 그대로입니다.
- **색칠** 탭: 부위를 고르고 색을 누르면 바로 칠해집니다.
